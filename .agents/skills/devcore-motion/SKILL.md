# Devcore Motion Design Skill

## Motion Principles
- Hierarchy: Micro (150-300ms), Standard (400-800ms), Cinematic (1-3s), Scroll (scrubbed).
- Scroll Choreography: Smooth scrub without jarring snaps. Pinning only for purposeful storytelling.
- Camera: Controlled, cinematic moves. Avoid abrupt perspective changes.
- Accessibility: Respect `prefers-reduced-motion` at all times. Disable camera fly-through and scrub for users requesting reduced motion.

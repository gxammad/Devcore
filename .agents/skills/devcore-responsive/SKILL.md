# Devcore Responsive Engineering Skill

## Mobile Adaptations
- Mobile is not a scaled-down desktop; it is a dedicated composition.
- Reduce 3D scene complexity: 75% fewer particle specks, lower instancing count for crystalline flora, simplified camera trajectory.
- Typography: Fluid responsive scaling with clamp() or Tailwind responsive utilities.
- Touch Targets: Minimum 44x44px clickable areas for all buttons and interactive controls.
- Custom Cursor: Completely disabled on touch devices.

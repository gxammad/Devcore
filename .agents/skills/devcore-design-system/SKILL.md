# Devcore Design System Skill

## Visual Language
- Aesthetic: Dark, minimal, architectural, cinematic, high-precision software engineering.
- Background: Obsidian/Void `#050608`, Surface `#0D0F12`, Elevated `#15181E`.
- Signature Accent: Cyber Emerald / Mint `#00F299` (used sparingly on CTAs, active nodes, data streams).
- Primary Text: Soft Off-White `#F2F5F8`.
- Secondary Text: Muted Charcoal `#8C96A5`.
- Subtle Borders: `rgba(255, 255, 255, 0.08)`.

## Typography
- Display: Geometric/Modern Grotesk (Space Grotesk / Inter Tight).
- Body: Neutral Modern Sans (Inter / Geist).
- Monospace: JetBrains Mono for system metrics, coordinates, micro-labels.
- Micro-labels: Uppercase, tracking `+0.20em`, 11-12px.

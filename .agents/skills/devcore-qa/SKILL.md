# Devcore Quality Assurance Skill

## QA Checklist
- Zero console errors and zero WebGL shader compilation warnings.
- Build compiles cleanly with zero TypeScript errors.
- Accessibility: Semantic HTML5 landmarks, visible focus outlines, high text contrast against dark surfaces.
- SEO: Metadata tags, OpenGraph, descriptive title, favicon.
- Browser Compatibility: Chrome, Edge, Safari, Firefox, iOS Safari, Android Chrome.

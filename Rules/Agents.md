# Devcore Project Rules

Devcore is a premium software engineering landing page.

The visual direction is:
dark
minimal
cinematic
technical
3D
spatial
premium

Never create a generic SaaS template.

Use the attached videos as visual references only.
Do not copy their artwork or branding.

The hero is the highest priority.

The hero should combine:
- cinematic 3D
- procedural growth
- camera movement
- scroll interaction
- parallax
- depth
- minimal typography

Prefer interactive 3D for elements controlled by scroll.

Use generated video only where video is technically more appropriate.

Prefer custom assets for signature Devcore visuals.

Prioritize:
1. visual quality
2. interaction quality
3. performance
4. accessibility
5. responsive behavior

Always test desktop and mobile.

Respect prefers-reduced-motion.

Do not add libraries unless they solve a real problem.
